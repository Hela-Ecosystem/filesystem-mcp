# HeLa Membrane: canonical tools

Server version **3.0.0**. Generated from the ecosystem schema catalog; regenerate with `npm run docs:generate -- --servers` in the ecosystem checkout.

Only names advertised by `tools/list` are listed here. Older aliases in migration examples are not additional tools. Runtime namespace prefixes are optional and do not change these server-local names.

## `archive_files`

Create archive from files

## `compare_files`

Compare two files and show differences

## `copy_file`

Copy file from source to destination

## `create_directory`

Create directory with optional recursive creation

## `delete_file`

Delete file or directory

## `extract_archive`

Extract archive to destination

## `find_files`

Find files matching a pattern

## `get_directory_size`

Get directory size recursively

## `get_file_info`

Get detailed file information including metadata

## `list_directory`

List directory contents with optional filtering and recursion

## `move_file`

Move file from source to destination

## `read_file`

Canonical local file read (use instead of hela-nucleus terminal_cat). Read file content with optional encoding and range

## `search_in_files`

Search for text patterns in files

## `stop_watching`

Stop watching a file or directory

## `watch_file`

Watch file or directory for changes

## `write_file`

Write content to file with optional encoding and directory creation
